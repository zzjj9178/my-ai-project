# 我的第一个AI智能应用 (My First AI App)

这是我参与云原生俱乐部实践项目的成果。从基础的 Linux 命令行操作，到使用 Docker 容器化部署，再到接入本地大语言模型 (LLM)，我完成了一个全栈云原生 AI 应用的搭建。

## 🛠️ 技术栈
*   **OS**: Linux (Ubuntu)
*   **容器化**: Docker, Docker Compose
*   **Web服务**: Nginx
*   **前端**: HTML/CSS/JS
*   **后端**: Python / Go
*   **AI**: 本地部署 LLM

## 📂 项目结构
*   `ai-chat/`：AI 助手前后端核心代码及 Docker 配置文件。
*   `deploy-ai-app/`：一键部署脚本及个人主页个性化配置。
