云原生 & K8s 架构

从 Linux 底座到 K8s 集群调度 · 现代互联网的基础设施

🐧 Linux —— 现代企业级 IT 工业的“地基”

从操作系统到底层服务器集群，掌握现代互联网的基石。

为什么企业服务器全都在跑 Linux？

无论是金融、电信、自动驾驶，还是当红的 AI 大模型推理集群，99% 的核心业务都运行在企业级 Linux （如 Red Hat Enterprise Linux）之上。它拥有无与伦比的长期稳定性、内存管理效率与内核级安全隔离。

大一我们需要掌握什么？

  • 告别图形界面的被动点击：熟悉 Shell 命令行的高效自动化；
  • 掌握系统核心底座：systemd 服务管理、LVM 逻辑卷存储、网络配置与排错；
  • 容器化环境支撑：为后续的 Docker 和 Kubernetes 搭建坚不可摧的宿主机运行环境。
💡 不靠死记硬背选择题，全程在真实服务器系统内动手排错，这就是大厂工程师的核心功底。

☁️ Kubernetes —— 调度海量算力的“云端超级计算机”

从单一容器编排，到大规模 GPU 集群调度的工业级事实标准。

云原生：不只是把代码传上云端

云原生（Cloud Native）由全球开源基金会 CNCF 定义。它的核心是利用容器化（Docker）、 微服务治理与声明式自动化，让复杂的分布式系统具备“永不宕机、秒级伸缩、故障自愈”的能力。

为什么连人形机器人与大模型都在用 K8s？

当成百上千张昂贵的 GPU 显卡同时跑模型训练，如何把任务合理分发给不忙的节点？ 当单台服务器硬件损坏，如何让业务瞬间转移而不影响用户？ K8s 就是负责在底层调度一切算力的“总指挥官”。

核心掌握技能

Pod 调度编排 多副本自动化扩缩容 集群网络通信 存储挂载 生产级系统故障排查

云原生俱乐部简介

西安工业大学 × CNCF 基金会共建 · 跨院校云原生技术平台

我们是谁

由学校官方与 CNCF 铂金会员红帽公司及引领云科技公司共建的学生社团。

西安工业大学云原生俱乐部（西安工业大学云原生技术俱乐部）由 西安工业大学 与 CNCF 基金会 共建， 红帽公司及引领云科技公司 参与支持，经学校官方授牌，专注于推广为 AI 大模型和边缘计算提供基础设施的云原生生态。
