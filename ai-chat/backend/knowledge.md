# 西安工业大学云原生俱乐部 · 参考资料

> 来源：2026 年秋季纳新宣讲会 PPT。供 AI 回答同学提问时作为事实依据，**不要编造本文件之外的信息**。

## 一、俱乐部是什么

- 全称：西安工业大学云原生俱乐部（西安工业大学云原生技术俱乐部）
- 由来：由**西安工业大学**与 **CNCF 基金会**共建，**红帽公司及引领云科技公司**参与支持，学校官方授牌
- 定位：**跨院校技术交流平台**。以西安工业大学云原生俱乐部为中心，先后孵化了**西安邮电大学、长安大学**等分支俱乐部
- 使命：掌握前沿技术，**竞赛、就业、升学全方面突破**
- 特色：坚持**老带新、全链路帮扶、项目实战驱动**
- 专注方向：为 **AI 大模型和边缘计算提供基础设施**的云原生生态

## 二、技术方向

- 技术底座：**Linux、Docker、Kubernetes** 及一系列相关技术栈
- 延伸出的岗位方向：**DevOps、SRE、AIOps**
- 一句话理解这个方向：*"软件开发是造车的，云原生是修高速公路的"* —— 保障海量并发与系统不崩溃，是企业的核心底盘

## 三、技术专家授课

- 技术专家来自 **红帽公司及引领云科技公司**，定期到校为同学传授前沿技术
- **以现场实操为主，不做纸上谈兵**
- 授课主题涵盖 **DeepSeek 大模型部署与应用**等技术栈

## 四、培养体系（三阶段）

1. **启动 · 云原生基石（大一大二）**：红帽 RHCSA 课程、Shell 编程、MySQL 数据库、Docker 容器课程。
   目标：打牢技术根基、通过 RHCSA 国际认证、解析国奖作品，能独立完成一个完整 Web 应用；可胜任运维开发岗、数据库管理员等工作。
2. **加速 · 云原生进阶（大三上）**：Kubernetes 集群管理、Ansible 自动化运维课程、中国电信 Hadoop 企业级项目课程。
   目标：深入理解容器编排精髓，完成企业级项目，指导组建团队、打磨项目，准备参与下一年度竞赛。
3. **冲刺 · AI 与云原生（大三下至秋招）**：Go 语言开发实战、CI/CD 与 GitOps 项目实战、AI Agent 项目（K8s SRE、RAG）实战。
   目标：掌握大厂所需 Go 语言，用 GitOps 搭建 CI/CD 流水线，冲刺 AI 智能体等竞赛与就业项目，成为**懂开发、懂架构、懂 AI 的全栈工程师**。

> 按学年的另一种说法：大一 Linux 操作系统管理 / Shell 自动化脚本 / MySQL / Docker 实操；大二 Kubernetes 集群搭建 / 企业级自动化运维 / Go 语言高并发编程；大三至大四 大模型部署与 AI 智能体（Agent）开发 / CI/CD 流水线 / 生产级 AIOps 监控。

## 十、认证与能力路径

- **RHCSA**（红帽认证系统管理员）：企业级 Linux 系统管理的黄金标准，考试全程实操，配置需重启后依旧生效，金融、政企、电信、医疗等核心行业高度认可，是通往 RHCE / RHCA 的第一级台阶
- **CKA**（认证 Kubernetes 管理员）：由 Linux 基金会与 CNCF 联合颁发，在真实集群内完成任务，厂商中立（EKS / GKE / AKS / 自建集群通用），是云原生 SRE、平台工程岗位的能力硬通货
- **俱乐部的观点**：RHCSA 打牢底层系统与 Linux 功底，CKA 覆盖上层容器编排；两者叠加，正好构成「底层系统 + 云原生编排」的完整能力链，也是名企面试最常问的两块。**两张证书不是终点，而是能力链的证明。**
